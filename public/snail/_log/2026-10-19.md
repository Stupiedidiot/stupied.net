What's funny about having matte coated keys is seeing the coat slowly fade away and seeing which key's you abuse. You can tell which keys is use the most based on how shiny it is. He's some keys that are faded out and my theory for why:

- **Tab, Shift, Ctrl, and Alt on the left -** I like my shortcuts. Funnily the capslock is untouched. I don't like the lack of feedback when tying capital letters, which I usually only do when programming. Personally prefer *italicizing* over using UPPERCASE when emphasizing words. The same keys on the right literally never get used. Mainly because the muscle memory for the controls are deeply ingrained on my left hand.
- **Letter K, X, C, and V -** Aside from the obvious reasons, It's also because of Krita. While drawing my left hand is resting on the keyboard while I look at my right hand on the tablet. To minimize margin of error when toggling common shortcuts, movement of left hand is lessen. K is for the transform tool, X is for the eraser, and C is for lasso selection tool. Aside from that, Krita's default shortcut are kept because their easy to remember. Also honorable mentions to S and A! They're awesome :)
- **Number 3 and 5 -** These two in particular get used a lot for Krita. The 3 key zooms out the canvas to fit view. The 5 key resets the rotation back to 0. My line are a lot straighter when doing them from top to bottom so the canvas gets rotate quite frequently. Zooming in too much is a habit I'm trying shake off so I periodically zoom out.
- **F1 and F2 Keys -** I've come to realize I'm really sensitive to light and have a habit of constantly adjusting the brightness.
- The rest are pretty self explanatory like the arrow keys, space bar, backspace and letter E.

### Other observation:
- **F8 Key -** Literally just found out that this key opens the display setting, which gets toggle often for my display tablet. I've literally never used this key and somehow the effort of putting my hand all the way to the tippy top of the keyboard is a lot more tiresome than clicking `windows + P`. In fact, the majority of the function keys are untouched. Even F4, since I rarely bother to close my windows
- **Brackets -** The open brackets key gets used up more often the close brackets key. This is probably because most text editor will auto complete it for you.
