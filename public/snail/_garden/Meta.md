Hello and welcome!! This is where we go about how things in this website was put together. Used to yap about this in my [blog](/blog/) but, because of how frequently the code is fiddles with, a lot of what I've written done becomes irrelevant. Soooooo, yeahhh!!! Expect this place to update often.

## The Beginning
This website was made impulsive created this website back in 2023 during my last year of junior High. It was inspired by [Literalhat](https://literalhat.com/) because of course it was. Had no prior knowledge about the indieweb culture and simply found [Neocities](https://neocities.org/) by googling "free hosting". Either way, I've learned a lot about the internet since I began working on this website and am forever indebted to those two things for helping find my passion for programming.

## Design Philosophy
I don't like wasting other people's time. If you come to my website to see my art, that is the first damn thing you're going to see. Which is also why I choose to have a "minimalist" design; Minimalist being relative to other Indieweb designs. Some people claim that using the same layout is *boring* and ***uncreative*** but I personally do not see it that way. I don't want to find myself endlessly writing the same thing for different layouts. I want to spend less time modifying the page for me to put my art in and spend more time actually making the art to put into the page.

## Technical Overview
I am a computer nerd (derogatory).
### Git
I use [Github](https://github.com/) for version control. It saves me the hassle of periodically making backup zip files. Also you can view this website's source code [here](https://github.com/Stupiedidiot/stupied.net)!
### Jekyll
[Jekyll](https://jekyllrb.com/) is the [Static Site Generator](https://en.wikipedia.org/wiki/Static_site_generator) (SSG) I use to make this website. Instead of manually copy and pasting html elements, you provide a template for the engine to wrap your content around. Jekyll is consider one of the "older" SSGs and is made with [Ruby](https://www.ruby-lang.org/en/)  but I continue use it because there isn't any features [other SSGs](https://jamstack.org/generators/) offer that entice me enough to put in the effort to switch. Jekyll is simple and I like that. If you want a more modern SSG made with [11ty](https://www.11ty.dev/) is frequently suggested by other Neocities users. There's also this [tutorial](https://petrapixel.neocities.org/coding/eleventy-tutorial) by Petrapixel that walks you through each step.

Anyways, Jekyll does most of the heavy lifting and I like to tweak it a bit to fit my needs. Still trying to fully wrap my head around object oriented programming so apologies for faulty information and my spaghetti code.

#### Sass / SCSS
Jekyll comes built in with [Sass](https://sass-lang.com/). It is a [Preprocessor](https://developer.mozilla.org/en-US/docs/Glossary/CSS_preprocessor) that will allow you to write styles with function and loops that will compile to CSS that the browser can read. Although vanilla CSS has come a long way, I'd rather not put the load of rendering all those rules on the users end.

I've tried using [Bootstrap](https://getbootstrap.com/) because I like their [grid system](https://getbootstrap.com/docs/5.3/layout/grid/), but I got annoyed of the amount of bloat and removing excess variables. Wouldn't say the attempt was a waste of time though because, through sifting through the code, I learned a few Sass tricks and better ways of managing my classes.

### Obsidian
[Obsidian](https://obsidian.md/) is my markdown editor of choice! All my [collections](https://jekyllrb.com/docs/collections/) are placed into folder called "snail" that I use as a vault. I use a handful of plugins but these are the essential ones:
- [Quick Add](https://github.com/chhoumann/quickadd) - Shortcut to creating new files
- [Better Properties](https://github.com/unxok/obsidian-better-properties) - adding icons and handling nested objects

### Javascript
I try to minimize my usage of Javascript. You may still navigate my website without it but it does provide some quality of life features. Javascript has a very special place in heart for being the first "real" programming language I've learned.
